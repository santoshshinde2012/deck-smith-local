# deck-smith-local

DeckSmith is the PowerPoint agent designed in [pptx-agent-databricks-research](https://github.com/santoshshinde2012/pptx-agent-databricks-research). This repository runs it on a laptop, using a stack shaped like Databricks, and is built with ports and adapters (SOLID).

This is the initial scaffold. The implementation arrives in the first pull request.
